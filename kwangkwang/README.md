# 쾅쾅 뭉치 — 땅속 바나나 대모험

진우를 위해 만든 2D 땅파기 모험 게임이에요. 땅을 쾅쾅 부수며 아래층으로 내려가는 게임에서 아이디어를 얻었고, 캐릭터·이야기·그림·음악·지도는 모두 새로 만들었어요.

## 실행하는 법

- `index.html`을 브라우저(크롬, 사파리, 엣지)로 열면 바로 시작해요. 설치할 것은 없어요.
- **파일 하나 버전**: `kwangkwang-moongchi.html` 하나에 게임 전체가 들어 있어요. 이 파일만 복사하거나 보내서 열어도 돼요. 인터넷이 없으면 글씨체만 기기 기본 글씨체로 바뀌고 게임은 그대로예요.
- 태블릿·휴대폰에서는 화면 버튼이 자동으로 나와요. 가로 화면이 더 넓게 보여요.
- 진행 상황(깬 층, 찾은 보석, 바나나, 모자)은 그 기기의 브라우저에 저장돼요.

## 이야기와 목표

욕심쟁이 **두더지 대왕**이 정글의 바나나를 몽땅 훔쳐 땅속으로 숨었어요. 고릴라 **뭉치**와 함께 땅을 부수며 내려가요.

| 층 | 이름 | 깨면 생기는 힘 |
|---|---|---|
| 1층 | 바나나 정글 | 잡아 던지기 |
| 2층 | 반짝 모래 동굴 | 슈퍼 뭉치 (바나나 40개 모으면 변신) |
| 3층 | 꽁꽁 얼음 동굴 | 왕주먹 (더 세고 넓게 부서짐) |
| 4층 | 부글부글 용암 동굴 | 대왕의 방 열림 |
| 맨 아래 | 두더지 대왕의 방 | 엔딩 |

- 층마다 **반짝 보석이 5개** 숨어 있어요. **3개**를 찾으면 아래층으로 가는 문이 열려요. 나머지 2개는 숨은 보석이에요.
- 바나나를 모으면 **옷장**에서 새 모자를 쓸 수 있어요 (150 / 400 / 700 / 1000개). 보석 20개를 모두 찾으면 황금 왕관을 받아요.
- 7살 아이에게 맞췄어요. 시간 제한이 없고, 하트가 다 없어져도 깃발에서 다시 시작하며, 모은 바나나와 보석은 그대로예요. 펀치 버튼은 꾹 누르고 있으면 계속 쳐요.
- 표지판 안내는 글자로 보여 주고, 기기에 한국어 목소리가 있으면 읽어 줘요. 설정에서 이름을 바꾸면 "진우야" 부분이 바뀌어요.

## 조작

| 동작 | 화면 버튼 | 키보드 | 게임패드 (스위치 프로콘 등) |
|---|---|---|---|
| 걷기 | ◀ ▶ | ← → | 스틱 / 십자키 |
| 점프 | 점프 | 스페이스 | B (아래 버튼) |
| 펀치 | 펀치 | Z | Y (왼쪽 버튼) |
| 땅 파기 | ▼ + 펀치 | ↓ + Z | 아래 + Y |
| 위로 펀치 | ▲ + 펀치 | ↑ + Z | 위 + Y |
| 쿵 내려찍기 | 공중에서 ▼ + 펀치 | 공중에서 ↓ + Z | 공중에서 아래 + Y |
| 벽 타기 | 벽 쪽으로 점프하고 화살표를 꾹 | 같음 | 같음 |
| 짝짝 (숨은 보석 찾기) | 짝짝 | C | X (위 버튼) |
| 잡기 · 던지기 | 잡기 | X | A (오른쪽 버튼) |
| 슈퍼 변신 | 슈퍼 | V | L / R |
| 잠깐 멈춤 | ❚❚ | Esc | + |

게임패드는 버튼 위치 기준이라 엑스박스 패드는 A 점프, X 펀치예요. 키보드는 WASD + J(펀치)·K(점프)·L(잡기)도 돼요.

## 파일 구성

```
kwangkwang/
  kwangkwang-moongchi.html   파일 하나 버전 (아래 파일들을 합쳐서 만든 것)
  index.html        화면, 메뉴, 버튼 모양
  js/maps.js        층 지도 (글자 한 칸 = 블록 한 칸)
  js/game.js        게임 규칙, 주인공, 적, 보스, 화면 흐름
  js/art.js         모든 그림 (캔버스로 그려요, 그림 파일 없음)
  js/audio.js       효과음, 배경음악, 목소리 안내 (소리 파일 없음)
  js/input.js       키보드, 화면 버튼, 게임패드
  tools/make_levels.py   지도를 만드는 파이썬 도구
  tools/build_single.py  파일 하나 버전을 다시 만드는 도구
```

`index.html`이나 `js/` 파일을 고쳤다면 `python3 tools/build_single.py`를 실행해서 파일 하나 버전도 새로 만들어 주세요.

## 지도 고치기

`js/maps.js`의 글자를 바꾸면 지도가 바뀌어요. 모든 줄의 길이는 같아야 하고, 바깥 테두리는 자동으로 깨지지 않는 돌로 둘러싸요.

| 글자 | 뜻 | 글자 | 뜻 |
|---|---|---|---|
| `.` | 빈칸 | `P` | 뭉치 시작 위치 |
| `#` | 깨지지 않는 돌 | `1`~`5` | 반짝 보석 (왼쪽 칸과 같은 블록 속에 숨음) |
| `d` | 흙 (1번에 부서짐) | `B` / `Q` | 바나나 / 바나나 송이 |
| `g` | 풀 덮인 흙 | `h` | 하트 |
| `s` | 돌 (2번) | `F` | 깃발 (다시 시작하는 곳) |
| `R` | 단단한 바위 (4번) | `D` | 문 (2칸 × 3칸, 왼쪽 위 칸에 표시) |
| `b` | 바나나 블록 | `T` | 표지판 (글은 `signs`의 "x,y"에) |
| `c` | 수정 블록 (바나나 5개) | `e` | 꼬마 두더지 |
| `x` | 폭탄 블록 | `v` | 박쥐 |
| `w` | 나무 상자 (하트) | `k` | 모래 게 (두 번 쳐야 함) |
| `=` | 나무 발판 (아래에서 통과) | `n` | 눈뭉치 두더지 |
| `L` | 용암 | `f` | 불꽃 젤리 |
| `^` | 가시 | `K` | 두더지 대왕 |
| `Y` | 금 간 유리 (던져야 깨짐) | | |

`tools/make_levels.py`로 지도를 다시 만들면 손으로 고친 `maps.js` 내용은 덮어써져요.
